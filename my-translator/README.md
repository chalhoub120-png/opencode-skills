# مترجم داخلي — استخدام شخصي

تطبيق ترجمة يعمل بالكامل على جهازك بدون إرسال أي بيانات للإنترنت.

## المتطلبات

- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Python 3.9+](https://www.python.org/)

## خطوات التشغيل

### 1. تشغيل محرك الترجمة الداخلي (Docker)

افتح موجه الأوامر في مجلد `my-translator` ثم نفذ:

```bash
docker-compose up -d
```

### 2. تثبيت متطلبات الخادم الداخلي (بايثون)

```bash
pip install flask flask-cors python-dotenv requests
```

### 3. تشغيل الخادم الداخلي (بروكسي)

```bash
python server.py
```

### 4. فتح التطبيق

افتح ملف `index.html` في متصفح الويب (كروم، إيدج، فايرفوكس).

سيفتح التطبيق على الرابط: `http://127.0.0.1:5500/index.html`  
أو semplicemente افتح الملف مرتين بالماوس.

## الميزات المفعلة

- ✅ واجهة مترجم بأناقة DeepL
- ✅ دعم اللغة العربية (اتجاه RTL)
- ✅ اكتشاف تلقائي للغة المصدر
- ✅ اختيار لغة الهدف من 15 لغة
- ✅ زر استبدال اللغات (⇄)
- ✅ زر نسخ الترجمة إلى الحافظة
- ✅ عداد الأحرف
- ✅ رسائل نجاح/خطأ
- ✅ تصميم متجاوب (هاتف/كمبيوتر)
- ✅ جميع البيانات تبقى على جهازك (خصوصية تامة)
- ✅ بدون تسجيل دخول، بدون اشتراك، بدون مفاتيح API خارجية

## ملاحظات الخصوصية

- لا يغادر أي نص جهازك أو شبكتك الداخلية.
- لا يتم تسجيل أو تخزين أي نصوص مترجمة.
- المنافذ مربوطة على `127.0.0.1` فقط (غير ظاهرة على الإنترنت).
