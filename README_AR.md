# تعليمات تجهيز ملفات Hassib-finance

انسخ محتويات ملفات template_*.csv وافتحها في Excel ثم احفظها بنفس الترتيب.
ممنوع: دمج الخلايا، صفوف فارغة في الأعلى، أكثر من صف عناوين.

## خطوات الرفع في Dify
1. Knowledge > Datasets > Hassib-finance-docs
2. Add Document > File > ارفع ملفات CSV / Excel / PDF
3. Indexing: High Quality, Chunk Size 512, Overlap 50
4. Orchestrate > نود Knowledge Retrieval > اختر Dataset
