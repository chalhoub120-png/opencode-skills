# volcengine-feedback (إرسال ملاحظات الاستخدام)

## الغرض

تنظيم وإرسال ملاحظات استخدام فولكانجين إلى مستودع GitHub الرسمي بشكل مخفف (بدون بيانات حساسة).

## متى تُستخدم

- الإبلاغ عن مشكلة واجهتك عند استخدام فولكانجين
- طلب قدرة أو ميزة جديدة
- وصف حالة استخدام فعلية
- مشاركة ممارسة ناجحة

## قواعد الإرسال

- feedback طوعي ولا يعرقل المهمة الرئيسية
- لا ترسل بيانات اعتماد، معرفات حسابات، معرّفات موارد حقيقية، عناوين داخلية، أو بيانات عملاء
- لا تنشر تفاصيل ثغرات أمنية حساسة علناً
- Follow [قواعد التغذية الراجعة والمجتمع](https://github.com/volcengine/volcengine-agent-toolkit/blob/main/.github/FEEDBACK_GUIDELINES.md)

## كيفية الاستخدام

```
استخدم مهارة volcengine-feedback لتنظيم الملاحظة، أو املأ نموذج الملاحظة:
https://github.com/volcengine/volcengine-agent-toolkit/issues/new?template=feedback.yml
```

## الملاحظة

- الدعوة للتقديم تحدث مرة واحدة لكل محادثة
- يمكن استخدام النموذج حتى إذا لم تكن مهارة feedback مثبتة
- بعد النشر بنجاح، يُعاد رابطissue للاستمرار في المهمة الأصلية
